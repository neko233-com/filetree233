# Changelog

## Unreleased

Restored the graphical interface as an opt-in `gui` feature; default builds stay command-line only. The interface is bilingual (English and Chinese) and follows the operating system language by default, with `--lang` and an in-window switch. Squarified treemap, classification colours, reclaimable hatching, keyboard navigation and a capacity panel. Marked directories feed the existing plan, confirmation code and revalidation pipeline, so there is no second deletion path. Release assets now include unsigned Windows MSI and zip, macOS DMG and Linux tar.gz; Linux packages stay command-line only to avoid display-server dependencies.

## 0.1.0-alpha.1

First preview: native GUI, CLI and MCP, explicit cleanup plan and confirmation, six platform builds and checksummed installers. See RELEASE_NOTES.md and README.md for important limitations.
